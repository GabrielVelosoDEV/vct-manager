Estrutura do clube — fotos dos departamentos (opcional).

Sem foto, a aba Estrutura desenha uma ilustração própria de cada departamento, que
ganha detalhes conforme o nível sobe. Uma foto aqui toma o lugar da ilustração no
cartão e na janela de níveis (o selo de nível continua por cima).

Formato: WebP (preferido), PNG ou JPG. Recomendado 1280×600 (proporção larga), sem
texto escrito e com o assunto no centro: o cartão corta as bordas.

Nome do arquivo = id do departamento:

| Departamento            | Arquivo          | O que mostrar                                   |
|-------------------------|------------------|-------------------------------------------------|
| Centro de treinamento   | `treino.webp`    | sala de treino / fachada de CT de esports       |
| Equipamentos            | `equip.webp`     | bancada com PCs, monitores, periféricos         |
| Sala de análise         | `analise.webp`   | telão com minimapa, sala de vídeo e dados       |
| Centro de performance   | `saude.webp`     | academia, fisioterapia, nutrição                |
| Psicologia e bem-estar  | `mente.webp`     | sala de descanso, ambiente calmo                |
| Gaming house            | `gh.webp`        | casa / sala de convivência do elenco            |
| Academia de base        | `academia.webp`  | jovens treinando, alojamento                    |

Depois de salvar, rode `npm run imagens` (o build já roda sozinho) para o jogo
enxergar o arquivo. Use só imagens que você tem direito de usar.

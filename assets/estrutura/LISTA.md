# Estrutura do clube — nomes que o jogo procura

Gerado por `npm run imagens` (o build roda sozinho). Não edite à mão.

Salve cada imagem aqui em `assets/estrutura/` com o nome exato da lista. O nome é o
id do departamento em minúsculas, sem acento, com hífen no lugar de espaço e símbolo.
PNG, JPG ou WebP servem: troque só a extensão.

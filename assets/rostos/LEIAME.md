# Pacote de retratos

Gerado por `tools/rostos.py` a partir do dataset **SFHQ (Synthetic Faces High
Quality)**, licença MIT — https://github.com/SelfishGene/SFHQ-dataset

As imagens são **sintéticas**: não são fotografias de pessoas reais. Foram
reduzidas, recortadas e tratadas com o grade escuro do jogo.

Trocar a quantidade de arquivos de um balde reembaralha os rostos daquele
balde, porque o jogo escolhe por `hash(id) % quantidade`. Para trocar uma
imagem, substitua o arquivo mantendo o nome.

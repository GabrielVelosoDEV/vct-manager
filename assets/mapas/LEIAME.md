Artes dos mapas.

Aparecem no veto e na pré-partida, na transmissão ao vivo e no medidor de preparo
de cada mapa (tela Treinamento & Preparação).

Nome do arquivo = nome do mapa em minúsculas. Formatos: WebP (preferido), PNG ou JPG.
Recomendado 1280×720 (16:9), sem texto escrito na imagem — o jogo escreve o nome por cima.

| Mapa     | Arquivo          |
|----------|------------------|
| Abyss    | `abyss.webp`     |
| Ascent   | `ascent.webp`    |
| Bind     | `bind.webp`      |
| Breeze   | `breeze.webp`    |
| Corrode  | `corrode.webp`   |
| Fracture | `fracture.webp`  |
| Haven    | `haven.webp`     |
| Icebox   | `icebox.webp`    |
| Lotus    | `lotus.webp`     |
| Pearl    | `pearl.webp`     |
| Split    | `split.webp`     |
| Summit   | `summit.webp`    |
| Sunset   | `sunset.webp`    |

Mapa novo no jogo (`MAP_POOL` em `data/mundo.js`) = arquivo novo aqui com o mesmo nome.

Sem arquivo, o jogo desenha um fundo com o nome do mapa — nada quebra.
